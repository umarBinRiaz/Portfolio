# Umar Bin Riaz — Portfolio

A modern, responsive personal portfolio for Umar Bin Riaz.

## Files

- `index.html` — portfolio structure
- `style.css` — complete responsive design
- `script.js` — projects and interactions

## GitHub Pages

Repository/project sites use this format:

`https://umarbinriaz.github.io/REPOSITORY-NAME/`

The project cards automatically build their Live and GitHub links from the repository name.

## Deploy

Put these files in a GitHub repository, push them to `main`, then enable GitHub Pages from:

Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`
